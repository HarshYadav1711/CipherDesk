# CipherDesk

Cybersecurity editorial and research homepage demo.

## Status

Phase 0 foundation complete. Homepage sections are not implemented yet.

## Stack

- Node.js 24 LTS
- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Geist (fonts package installed; wiring in Phase 1)
- Lucide React
- Prettier + ESLint

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm start
```
